# 🤖 Virtual AI Assistant

A web-based **Virtual AI Assistant** built using the **MERN Stack**, **Web Speech API**, and **Gemini API**.
The assistant allows users to interact using **voice commands or text**, enabling natural conversations and smart responses powered by AI.

## 🧠 Overview

Virtual AI Assistant is an intelligent web application that enables users to interact with an AI-powered assistant through voice or text.
It uses **speech recognition and speech synthesis** for voice interaction and **Gemini API** for generating intelligent responses.

The assistant can understand commands, answer questions, and perform useful tasks through a simple web interface.

↓

↓

↓

## 🚀 Usage

1. Open the application in your browser.
2. Click on the **microphone icon** to start voice input.
3. Speak your command or type a message.
4. The AI assistant processes the request using **Gemini API**.
5. The response is displayed and optionally spoken aloud.
